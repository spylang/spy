# <img src="assets/logo.svg" width="60" style="vertical-align: middle;"> SPy

SPy is a variant of Python designed to be statically compilable **while**
retaining many of the "useful" dynamic parts of Python. It comes with:

  1. an **interpreter**, for the usual nice Python development experience;
  2. a **compiler**, for speed: it targets native executables and WebAssembly.
